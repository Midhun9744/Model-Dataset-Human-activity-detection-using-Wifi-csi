# Human Activity Recognition Using Wi-Fi CSI

A Human Activity Recognition (HAR) system that uses Wi-Fi Channel State Information (CSI) and Deep Learning models to detect and classify human activities such as walking, sitting, standing, and falling without requiring wearable sensors or cameras.

## Overview

This project leverages Wi-Fi CSI data to recognize human activities by analyzing variations in wireless signal propagation caused by human movement. The system processes CSI data, extracts meaningful features, trains machine learning/deep learning models, and provides real-time activity prediction through a web and mobile interface.

## Features

- Wi-Fi CSI-based activity recognition
- Non-intrusive and privacy-preserving monitoring
- Real-time activity prediction
- Fall detection for safety monitoring
- Activity history tracking
- Mobile application
- User authentication and activity logs
- Deep Learning-based classification

## Activities Detected

- Walking
- Sitting
- Standing
- Falling

## Dataset

The project uses a Wi-Fi CSI Human Activity Recognition dataset containing CSI measurements collected from Wi-Fi devices under different human activities.

### Dataset Characteristics

- Channel State Information (CSI) measurements
- Multiple activity classes
- Time-series wireless signal data
- Labeled activity samples
- Indoor environment recordings
